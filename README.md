# Security Auditing Lab

## Objective
This project was completed as part of the Google Cybersecurity Professional Certificate. Its objective was to evaluate Botium Toys’ overall security posture by identifying existing controls, uncovering vulnerabilities, and assessing compliance with standards such as PCI DSS, GDPR, and the NIST Cybersecurity Framework. The audit focused on mapping assets, analyzing organizational risks, and producing actionable, prioritized recommendations to strengthen defenses, improve incident readiness, and support a more resilient security environment.

### Skills Learned
- Security auditing fundamentals — evaluating administrative, technical, and physical controls
- NIST CSF application — mapping controls across Identify, Protect, Detect, Respond, and Recover
- Risk assessment & analysis — determining likelihood, impact, and prioritizing risks
- Compliance evaluation — referencing PCI DSS, GDPR, and other regulatory requirements
- Asset identification & classification — documenting critical systems and data flows
- Gap analysis — comparing existing controls against recommended security measures
- Threat modeling — identifying potential attack vectors and weaknesses
- Control assessment — reviewing policies, procedures, and technical safeguards
- Report writing & documentation — producing clear, actionable recommendations
- Security governance awareness — understanding roles, responsibilities, and policy structure
- Professional communication — presenting findings in a structured, business‑friendly format


### Tools Used
- Security Auditing Checklist – to evaluate controls and identify gaps
- NIST Cybersecurity Framework (NIST CSF) – for control mapping and risk categorization
- PCI DSS & GDPR Requirements – for compliance assessment
- Asset Inventory Template – to identify and classify organizational assets
- Risk Assessment Matrix – to evaluate likelihood, impact, and prioritize risks
- Control Evaluation Worksheet – to review administrative, technical, and physical controls
- Threat Modeling Worksheet – to identify attack vectors and weaknesses
- Report Writing Template – to document findings and recommendations
